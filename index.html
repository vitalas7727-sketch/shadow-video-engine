01

Добавь ключ AI-видеогенерации

В GitHub открой репозиторий shadow-video-engine → Settings → Secrets and variables → Actions → New repository secret.

Имя секрета: FAL_KEY. Значение — API-ключ из кабинета fal.ai.

02

Права GitHub-токена

Fine-grained token должен иметь доступ к репозиторию shadow-video-engine и права:

  • Contents — Read and write
  • Actions — Read and write
  • Workflows — Read and write
03

Запусти проект

На вкладке «Создать видео» выбери изображение, опиши сцену, добавь текст диктора и нажми кнопку запуска. Приложение загрузит материалы в репозиторий и запустит облачную сборку.

Важно о стоимости

AI-видеогенерация через fal.ai платная. Стоимость зависит от модели, длительности и тарифа. Перед первым запуском проверь баланс и цены в кабинете fal.ai. Ключ FAL_KEY не вводится в приложение — он хранится в секретах GitHub.
