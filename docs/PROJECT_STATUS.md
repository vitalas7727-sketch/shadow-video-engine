# Shadow Video Engine — паспорт проекта

Обновлено: 24 ноября 2026 года

## 1. Назначение

Shadow Video Engine — разрабатываемая AI-видеостудия.
Цель — создание видео из изображений и текстовых описаний сцен,
с последующим монтажом, озвучкой, музыкой и экспортом MP4.

Главный приоритет — бесплатные инструменты и локальная обработка.
Платные AI-запросы запрещены без отдельного разрешения владельца проекта.

## 2. Владелец и рабочие условия

Владелец проекта: Виталий.

Устройство разработки: Samsung Galaxy A13, Android 14.
Рабочая среда: Termux, Git и GitHub.
Компьютер отсутствует.

Команды должны быть удобны для копирования в Termux.

## 4. Текущая версия

Текущая основа приложения — Shadow Video Engine 0.2.

Подтверждённые возможности исходного кода:
- PWA-интерфейс;
- загрузка исходного изображения;
- текстовый промпт сцены;
- выбор длительности 5 или 10 секунд;
- визуальные пресеты;
- необязательная музыка;
- русская озвучка через Edge TTS;

- итоговый MP4 с H.264 и AAC.

## 5. Важные ограничения и риски

### Платная генерация

В render_ai.py предусмотрен вызов Kling 2.6 Pro через fal.ai.
Это платная генерация.

Не запускать платные запросы и не расходовать средства без
отдельного явного разрешения Виталия.

### Публичная загрузка материалов

Текущий app.js использует GitHub Contents API для загрузки
изображений и музыки в публичный репозиторий.

Такие материалы могут стать публично доступными.
Не загружать личные фотографии, аудио и конфиденциальные файлы.

До изменения архитектуры хранения использовать только
тестовые материалы, которые разрешено публиковать.

### Service Worker

В опубликованной версии ранее обнаружен cache:
shadow-video-engine-shell-v2.

Требуется безопасное обновление:
- использовать собственный префикс shadow-video-engine-shell-;
- удалять только старые кэши приложения;
- кэшировать только файлы оболочки;
- не перехватывать посторонние API и запросы с авторизацией.

Перед изменением проверить фактические пути файлов и иконок.

### Разрешение видео

Текущая команда FFmpeg использует копирование видеопотока.
Фиксированная нормализация до 720p пока не подтверждена.

Планируемые профили:
- горизонтальное видео: 1280×720;
- вертикальное видео: 720×1280;
- сохранение пропорций;
- H.264, AAC, 24 FPS.

## 6. Целевая архитектура

Планируемые возможности:
- простой и профессиональный режимы;
- Prompt Builder;
- многосценные проекты;
- Character Lock и фиксация внешности персонажа;
- Costume Lock, Color Lock, Prop Lock, Location Lock, Style Lock;
- Continuity Check;
- референсные изображения;
- форматы 16:9, 9:16, 1:1, 4:5, 4:3 и 21:9;
- монтаж, озвучка, музыка, субтитры и эффекты;
- каталог AI-провайдеров с информацией о стоимости, квотах,
  лицензиях и доступности.

Бесплатные провайдеры — основной приоритет.
Нельзя обещать неограниченную бесплатную генерацию.
Нельзя автоматически переключаться на платные сервисы.
